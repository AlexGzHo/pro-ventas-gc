# Roadmap

Después de estabilizar el MVP se pueden evaluar, en este orden aproximado:

- Plantillas de WhatsApp editables desde la aplicación.
- Historial de renovaciones y pagos.
- Importación inicial desde Excel/CSV.
- Reporte por mes.
- Exportación a Excel/CSV.
- Registro de quién modificó cada venta.
- Copias de seguridad guiadas.
- Cifrado adicional de credenciales almacenadas.
- Roles si en el futuro ingresan más trabajadores.

No son requisitos para publicar la primera versión.
